SECTION 01

Agile Team Charter

A social contract defining team purpose, roles, working agreements, and operational boundaries.

Evidence & Artifacts

  • Role: Database Developer (Database design, schema implementation, SQL query optimization)
  • Core Values: Transparency, peer code reviews, daily stand-up communication
  • Working Agreements: Trello for task tracking, Git branching strategy for features

Core Objective

Establish clear operational guidelines to reduce friction, resolve team conflicts quickly, and ensure clear database integration contracts across backend services.

Reflection & Learning

Building the Agile Team Charter provided crucial insight into how explicit team agreements directly minimize friction during high-pressure development cycles. As a Database Developer, defining clear boundaries around data requirements early in the project prevented scope creep and database schema mismatches during API integration.

SECTION 04

Sprint Backlog

An actionable plan outlining specific work needed to achieve the sprint goal.

Sprint Goal

Deliver a functional MVP core enabling local job seekers to search, filter, and view details for active job listings in Belhar.

Sprint Deliverables

  • Relational SQL schema created for Users and Job Posts
  • Stored procedures implemented for category filtering
  • API controllers connected to search UI

Reflection & Learning

The Sprint Backlog translated strategic product goals into immediate operational execution over a fixed iteration. Reflecting on sprint execution revealed how database preparedness directly impacts sprint velocity. Having predefined SQL models ready at the start of the sprint enabled backend API development to proceed smoothly.
