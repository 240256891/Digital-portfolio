Team Charter User Stories Product Backlog Sprint Backlog Agile Logbook

1. Agile Team Charter

Evidence

Our team charter serves as a working contract outlining roles, communication agreements, and values.

  • Role: Database Developer (Schema design, SQL execution, Query performance)
  • Artifact Link: View Team Charter Document

Reflection

Defining clear working agreements early mitigated communication friction during backend integration. Aligning data models prior to development prevented schema mismatches during sprint cycles.

2. User Stories and Tasks

Evidence

User stories focus on user value and form the basis of our task breakdowns on Trello.

Story ID User Story Tasks
US-01 As a job seeker, I want to filter local job listings by category so that I can find work nearby. 1. Build SQL index
2. Develop REST endpoint
3. Connect search UI

Reflection

Deconstructing features into granular tasks ensured that database schemas were directly aligned with business features, avoiding unnecessary data redundancy.

3. Product Backlog

Evidence

Prioritized using the MoSCoW framework to manage core deliverables.

  • Must Have: User Auth, Job Posting Storage Engine, Search & Filter
  • Should Have: In-App Employer Communication
  • Could Have: Job Rating System

Reflection

Continuous backlog prioritization forced us to evaluate technical dependencies early, proving that database structural setup must precede complex query features.

4. Sprint Backlog

Evidence

Focuses on delivering a functional search and filtering MVP for local users.

  • Sprint Goal: Build end-to-end local search and filtering capabilities.
  • Status: Relational schema created, search stored procedures active, API integrated.

Reflection

Keeping sprint commitments tightly focused prevented scope creep and allowed all planned story points to be completed on time.

5. Agile Logbook

Evidence

Daily stand-up logs and retrospective action items track progress and operational blockers.

Stand-Up Excerpt: Finalized database queries for category filtering; integrated endpoints with frontend UI.

Reflection

Maintaining a daily log provided operational visibility, ensuring continuous delivery across all project milestones.
